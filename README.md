### Currently building

**Chain of Custody: Digital Forensic Locker** · final year project, in progress

Tamper-evident custody for digital evidence. Files are hashed with SHA-256 and
stored on IPFS, with only the 46-byte content identifier anchored to a Solidity
contract on Ethereum, which keeps gas cost far below writing payloads on chain.
An append-only audit trail records every custody transfer, so reconstructing
provenance is an indexed contract query rather than hours of reading logs.

*Repository stays private until the project has been evaluated.*
